# 🍈 Goiaba.DB

O **Goiaba.DB** é um projeto de sistema de gerenciamento para restaurantes, desenvolvido com o objetivo de praticar e aprimorar conhecimentos em **bancos de dados e desenvolvimento de sistemas**.

O sistema foi pensado para centralizar diferentes áreas da operação de um restaurante, facilitando o gerenciamento de produtos, estoque, caixa, pedidos e pagamentos.

## 🎯 Objetivo

O principal objetivo do **Goiaba.DB** é desenvolver um sistema que simule o funcionamento de um restaurante, integrando diferentes setores em uma única solução.

O projeto contempla funcionalidades como:

* 📦 **Gerenciamento de estoque** <br>
* 💰 **Gerenciamento de caixa**  <br>
* 🍽️ **Gerenciamento de produtos e pedidos** <br>
* 🛵 **Integração com delivery**  <br>
* 💳 **Gerenciamento de métodos de pagamento**  <br>
* 📊 **Controle e organização das informações do restaurante** <br>

## 🗄️ Banco de Dados

O projeto utiliza um banco de dados para armazenar e relacionar as informações do sistema, permitindo trabalhar conceitos como:

* Criação e relacionamento entre tabelas  <br>
* Chaves primárias e estrangeiras  <br>
* Operações CRUD  <br>
* Consultas SQL  <br>
* Relacionamentos entre entidades  <br>
* Controle de estoque  <br>
* Registro de vendas e pagamentos  <br>
* Gerenciamento de pedidos  <br>

## 🚀 Status do Projeto

🟡 **Em desenvolvimento**

O projeto será desenvolvido gradualmente, com novas funcionalidades sendo adicionadas conforme o avanço dos estudos.

## 📚 Objetivo de Aprendizagem

O **Goiaba.DB** é um projeto desenvolvido para fins de **estudo e aprendizado**, buscando aplicar na prática conceitos de banco de dados e desenvolvimento de sistemas.
